
# PIRNN-AKF实验设计完整方案

## 一、实验目标

### 1.1 主要目标
- 验证PIRNN-AKF相比基准方法的估计精度提升
- 评估物理约束损失对模型泛化能力的贡献
- 测试自适应机制对突发阵风的响应性能
- 验证算法在嵌入式平台上的实时性

### 1.2 待验证假设
- H1: 物理信息约束可提高神经网络在未见风况下的泛化能力
- H2: 自适应协方差机制能有效应对动态风场变化
- H3: 混合架构优于纯模型或纯数据驱动方法

**工具**: JSBSim飞行动力学引擎

**无人机模型**: Skywalker X8固定翼
- 翼展: 2.1m
- 质量: 2.5kg
- 巡航速度: 15-18 m/s
- 气动参数: 从JSBSim模型库提取

### 2.2 风场生成器

#### 2.2.1 Dryden湍流模型（MIL-F-8785C标准）
```python
# 关键参数设置
湍流强度等级:
- 低度: σ_w = 1.0 m/s
- 中度: σ_w = 2.0 m/s  
- 重度: σ_w = 4.0 m/s

频率特性:
- 低空轻度湍流: L_w = 533m
- 低空中度湍流: L_w = 200m
```

#### 2.2.2 复合风场构成
**总风矢量**: W(x,y,z,t) = W_mean + W_turb + W_shear + W_gust

| 风分量 | 数学模型 | 参数范围 |
|--------|----------|----------|
| 平均风 | 常值/缓变 | 8-12 m/s |
| 湍流 | Dryden谱滤波白噪声 | σ=1~4 m/s |
| 风切变 | 对数剖面: W(h)=W_10(h/10)^α | α=0.14 |
| 离散阵风 | 1-cosine脉冲 | 幅值3-6 m/s, 持续2-5s |

### 2.3 传感器建模

| 传感器 | 噪声类型 | 标准差 | 更新率 | 附加误差 |
|--------|----------|--------|--------|----------|
| GPS速度 | AWGN | 0.1 m/s | 5 Hz | 量化误差0.01 m/s |
| IMU加速度计 | AWGN+偏置漂移 | 0.05 m/s² | 50 Hz | 偏置0.02 m/s² |
| IMU陀螺仪 | AWGN+随机游走 | 0.002 rad/s | 50 Hz | - |
| 皮托管 | AWGN | 2.0 m/s | 20 Hz | 校准误差±5% |

## 三、对比基准方法

### 3.1 基准算法

#### Baseline 1: 标准EKF
- **实现**: 基于风三角关系的运动学模型
- **状态**: [v_g^n, W^n]^T
- **固定协方差**: Q, R设为常量
- **参考**: Chao et al. (2014)

#### Baseline 2: 朴素GRU
- **架构**: 与PIRNN相同（2层GRU, 隐藏层64）
- **损失**: 仅L_data (MSE)
- **训练数据**: 与PIRNN相同

#### Baseline 3: 改进型自适应卡尔曼滤波（IAKF）
- **自适应机制**: 基于新息的Sage-Husa估计器
- **无神经网络补偿**: 仅依赖运动学模型
- **参考**: Liu et al. (2021)

#### Baseline 4 (可选): LSTM-KF
- **架构**: LSTM代替GRU
- **目的**: 证明GRU在计算效率-性能的平衡优势

### 3.2 对比指标

#### 3.2.1 精度指标
```
RMSE(均方根误差):
RMSE = sqrt(1/N * Σ(W_est - W_true)²)

MAE(平均绝对误差):
MAE = 1/N * Σ|W_est - W_true|

分方向统计: RMSE_north, RMSE_east, RMSE_down
```

#### 3.2.2 动态响应指标
- **调节时间** (Settling Time): 达到±5%误差带的时间
- **超调量** (Overshoot): 峰值误差百分比
- **稳态误差** (Steady-state Error): 收敛后的平均误差

#### 3.2.3 泛化指标
- **分布内测试** (In-Distribution): 训练分布内的风速
- **分布外测试** (Out-of-Distribution): 1.5倍训练风速
- **性能衰减率** = (RMSE_OOD - RMSE_ID) / RMSE_ID

#### 3.2.4 计算性能
- **推理时间** (Inference Time): 单步耗时(ms)
- **CPU占用率**: 百分比
- **内存占用**: MB

## 四、数据集设计

### 4.1 训练数据集

#### 4.1.1 飞行场景
| 机动类型 | 时长 | 速度范围 | 高度范围 | 目的 |
|----------|------|----------|----------|------|
| 直线飞行 | 100次×2min | 12-18 m/s | 50-150m | 基本运动学 |
| 盘旋 | 100次×3min | 15 m/s | 80-120m | 转弯动力学 |
| "8"字机动 | 50次×5min | 14-17 m/s | 80-120m | 连续转弯 |
| 爬升/下降 | 50次×2min | 15 m/s | 50-200m | 垂直风梯度 |

#### 4.1.2 风况分布
- **训练集风速**: 均匀分布在6-14 m/s
- **湍流强度**: 轻度+中度混合
- **阵风频率**: 每飞行10分钟注入2-3次

**数据增强**:
- 时间序列平移
- 传感器噪声级别随机化(±30%)
- 风向角度随机化(0-360°)

**总样本量**: 约300次飞行 × 600秒 × 50Hz = 9M个样本点

### 4.2 测试数据集

#### 4.2.1 分布内测试集（ID）
- 50次飞行，风况与训练集相似
- 用于验证基本估计精度

#### 4.2.2 分布外测试集（OOD）
| 测试类型 | 变化内容 | 目的 |
|----------|----------|------|
| OOD-高风速 | 风速18-22 m/s (1.5倍) | 泛化能力 |
| OOD-重度湍流 | σ_w = 5.0 m/s | 极端扰动 |
| OOD-低速飞行 | 10-12 m/s | 可观测性退化 |
| OOD-剧烈机动 | 高坡度转弯(45°) | 非线性动力学 |

#### 4.2.3 鲁棒性测试集
**阵风注入实验**:
- 时刻: t=200s
- 类型: 1-cosine离散阵风
- 幅值: 3/6/9 m/s三组
- 持续时间: 2/3/5s三组
- **总组合**: 3×3 = 9种场景 × 20次重复

## 五、消融实验设计

### 5.1 物理损失权重影响
**实验组**:
| 组别 | λ_phy | 目的 |
|------|-------|------|
| A0 | 0.0 | 纯数据驱动(对照组) |
| A1 | 0.01 | 弱物理约束 |
| A2 | 0.1 | 中等约束(论文推荐) |
| A3 | 1.0 | 强物理约束 |
| A4 | 10.0 | 过度约束(预期性能下降) |

**评估**: 在OOD测试集上比较RMSE和训练收敛曲线

### 5.2 自适应机制有效性
**对比组**:
1. **无自适应**: Q, R固定
2. **仅基于新息自适应**: 无神经网络置信度c_t
3. **完整PIRNN-AKF**: 置信度驱动的自适应

**测试场景**: 阵风注入实验

### 5.3 网络架构消融
| 组件 | 变体 | 目的 |
|------|------|------|
| 循环单元 | GRU / LSTM / Vanilla RNN | 选择最优架构 |
| 隐藏层大小 | 32 / 64 / 128 | 容量-效率平衡 |
| 层数 | 1 / 2 / 3 | 深度影响 |

### 5.4 课程学习策略影响
**对比训练方式**:
1. **直接训练**: 直接使用λ_phy=1.0
2. **课程学习**(论文方法): 三阶段渐进
3. **反向课程**: 先物理后数据

## 六、实验流程

### 6.1 训练阶段

#### 阶段1: 预热 (Epoch 1-20)
```python
损失: L = L_data
数据: 简单恒定风场(8 m/s)
学习率: 1e-3
批量大小: 256
目的: 稳定GRU权重初始化
```

#### 阶段2: 物理注入 (Epoch 21-60)
```python
损失: L = L_data + 0.1 * L_phy
数据: 复杂Dryden湍流
学习率: 5e-4 (余弦退火)
数据增强: 启用
```

#### 阶段3: 微调 (Epoch 61-100)
```python
损失: L = L_data + 1.0 * L_phy
学习率: 1e-4
早停: 验证集误差连续5轮不降
```

**优化器**: AdamW (weight_decay=1e-4)
**正则化**: Dropout=0.2
