
# 训练数据轨迹多样性设计指南

## 问题阐述

**核心问题**：300次飞行中，直线飞行100次×2分钟，这100次直线飞行是否可以使用同一条直线？包括其他的盘旋、8字机动、爬升下降，都可以是同一个轨迹吗？

**简短回答**：**绝对不能是同一条轨迹**。必须大幅随机化轨迹参数，否则神经网络会过拟合，导致泛化能力严重下降。

---

## ❌ 为什么不能重复同一轨迹？

### 1. 数据多样性不足

如果100次直线飞行都是：
- 同样的航向（比如都是正北向）
- 同样的风向角（风总是从侧面吹）
- 同样的GPS-IMU配置

神经网络会**过拟合**这个特定场景，导致：
- 换个航向就失效（如东西向飞行）
- 泛化能力严重下降
- 物理损失的优势无法体现

### 2. 可观测性退化

风场估计依赖于：
- **不同航向**下的GPS速度-空速差异
- **不同姿态角**下的力矩平衡
- **多样化机动**激发的动力学响应

单一轨迹无法提供足够的**观测维度**，类似于用单一视角无法重建3D物体。

### 3. 实际应用场景不匹配

真实飞行任务中：
- 无人机需要在各种航向上飞行
- 风向与航向的相对角度随时变化
- 不同高度层的风场特性差异显著

训练数据必须反映这种**多样性**，才能保证算法在实际部署时的鲁棒性。

**风切变模型示例**：
```python
# 对数风剖面
def wind_shear_profile(height, wind_10m=10.0, alpha=0.14):
    """
    height: 当前高度 (m)
    wind_10m: 10米高度处的风速 (m/s)
    alpha: 地表粗糙度指数 (0.14为开阔地带)
    """
    return wind_10m * (height / 10.0) ** alpha
```

### 实施步骤

#### 步骤1：生成随机化数据（180次）

```python
import numpy as np
import random

def generate_random_flights(num_flights, config):
    """
    生成随机化飞行数据
    
    参数:
        num_flights: 飞行次数
        config: 配置字典，包含各类参数范围
    """
    flights = []
```

```python
def validate_dataset(flights):
    """自动验证数据集质量"""
    
    print("开始数据集质量检查...")
    print("=" * 60)
    
    issues = []
    
    # 1. 检查航向覆盖
    headings = [f['heading'] for f in flights if 'heading' in f]
    sectors = np.digitize(headings, bins=np.arange(0, 360, 45))
    sector_counts = np.bincount(sectors, minlength=9)[1:]  # 去掉0索引
    
    if np.min(sector_counts) < 10:
        issues.append(f"⚠️  某些航向扇区样本不足: {sector_counts}")
    else:
        print(f"✓ 航向覆盖: 各扇区均>10次")
    
    # 2. 检查风速范围
    wind_speeds = [f['wind_speed'] for f in flights]
    if max(wind_speeds) < 13 or min(wind_speeds) > 7:
        issues.append(f"⚠️  风速范围不足: [{min(wind_speeds):.1f}, {max(wind_speeds):.1f}] m/s")
    else:
        print(f"✓ 风速范围: [{min(wind_speeds):.1f}, {max(wind_speeds):.1f}] m/s")
    
    # 3. 检查类型分布
    type_counts = {}
    for f in flights:
        ftype = f['type']
        type_counts[ftype] = type_counts.get(ftype, 0) + 1
    
    print(f"✓ 类型分布: {type_counts}")
    
    # 4. 检查重复轨迹
    trajectory_signatures = []
    for f in flights:
        sig = (
            f.get('heading', 0),
            f.get('altitude', 0),
            f.get('airspeed', 0),
            f.get('radius', 0)
        )
        trajectory_signatures.append(sig)
    
    from collections import Counter
    sig_counts = Counter(trajectory_signatures)
    max_repeat = max(sig_counts.values())
    
    if max_repeat > 3:
        issues.append(f"⚠️  存在重复轨迹（最多重复{max_repeat}次）")
    else:
        print(f"✓ 轨迹多样性: 最多重复{max_repeat}次")
    
    # 总结
    print("=" * 60)
    if issues:
        print(f"发现 {len(issues)} 个问题:")
        for issue in issues:
            print(issue)
        print("\n建议: 调整数据生成参数后重新生成")
    else:
        print("✅ 所有检查通过！数据集质量合格")
    
    return len(issues) == 0
```

## 🎯 总结与建议

### 关键要点

1. **绝对不能重复相同轨迹** - 这是训练成功的前提
2. **推荐混合方案** - 60%随机 + 30%关键场景 + 10%边界条件
3. **每次飞行必须改变风场** - 即使轨迹相似，风况也要不同
4. **验证数据多样性** - 使用检查清单确保覆盖充分

### 实施优先级

**高优先级**（必须做）:
- ✅ 航向随机化（0-360°均匀分布）
- ✅ 风向随机化（覆盖相对风向各象限）
- ✅ 高度分层（低/中/高空）

**中优先级**（强烈推荐）:
- ⭐ 速度变化（12-18 m/s）
- ⭐ 盘旋半径和方向多样化
- ⭐ 关键场景设计（强侧风、顺逆风）

**低优先级**（锦上添花）:
- 💡 复杂组合机动（爬升-盘旋-下降）
- 💡 边界条件测试
- 💡 数据增强（时间平移、噪声级别随机化）

### 预期效果

正确实施多样化数据采集后，你的PIRNN-AKF应该能够：
- ✅ 在**任意航向**下准确估计风场
- ✅ 在**各种风况**下保持鲁棒性
- ✅ 在**OOD测试**中性能衰减<20%
- ✅ 超越基准方法**40-65%**的RMSE提升
